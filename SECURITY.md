# Report a security vulnerability

In the GitHub repository, open **Security and quality** and select **Report a vulnerability** to submit a private report. If the button is missing, open an issue asking for a private contact and keep the vulnerability details out of the issue. [GitHub private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately)

Include the app version or commit, your macOS version, the steps to reproduce, and the potential impact. Use synthetic accounts and passwords. Remove real credentials, Keychain files, and CSVs that contain real passwords from attachments.
